# Prompt Picker 0.1.6

**18+.** Prompt Picker is for adults. The first launch asks "Are you 18 or older?" Yes is remembered on this PC. No closes the app.

## Levels and usage notes

- Rating is now Level. Mild was SFW, Explicit was NSFW, and All levels was All.
- Older files and the paste form `[SFW]` / `[NSFW]` / `[ALL]` still import and are shown with the new names.
- Each prompt can have a usage note: which character to use and what to add. It is separate from the short note in the name. It appears in the edit form, in a collapsible block on the card, under the picked prompt, and in JSON import, export, the sample template, and the AI guide.

## Look and windows

- Theme colors: Primary, Secondary, app background, and panel background, with a hue ring and a saturation square. Text contrast follows the colors. Reset to default is in Theme colors.
- Settings opens in its own window. The main window updates immediately. The gear button brings that window forward if it is already open.
- Font size scales the whole interface from 90% to 150%, including Ctrl+=, Ctrl+-, and Ctrl+0.
- Narrow windows stack columns. Below about 600 pixels the main window uses a phone layout: one column, full-width controls, a scrollable tab bar, one card per row, and images above the text.

## Updates and fonts

- The app checks for a new version when it opens and about every 30 minutes.
- When a newer version exists, Update now is highlighted beside Check for updates and shows the version number. It downloads and installs over this copy and does not delete prompts.
- Settings has an Updates tab with the current version, the latest version, and release notes from GitHub.
- English and Vietnamese use Be Vietnam Pro, including Vietnamese diacritics. Chinese uses Noto Sans SC. Korean uses Noto Sans KR. The fonts are included in the app.

## Install

`PromptPicker-Setup-0.1.6.exe` and `latest.yml` are the auto-update files. Leave those names as they are.

`PromptPicker-0.1.6-Windows.zip` contains the Setup exe, the install guide in English, Vietnamese, Chinese, and Korean, and illustration images.

Windows may say "Windows protected your PC" because this app is not code-signed. Choose More info, then Run anyway. That warning is expected. Do not turn off SmartScreen or Defender. The pictures in the guide are illustrations, not screenshots of your PC.

The installer lists Lineko as the publisher name. Code signing is not available for this build because there is no signing certificate.
