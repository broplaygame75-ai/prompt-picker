# Prompt Picker 0.1.14

**18+.** Prompt Picker is for adults. The first launch asks "Are you 18 or older?" Yes is remembered on this PC. No closes the app.

## Update from 0.1.12

- The 0.1.12 updater starts setup without a folder. 0.1.14 installs into the existing folder, including `%LOCALAPPDATA%\Programs\Prompt Picker`. It does not add a second copy in `C:\Prompt Picker`.
- A silent upgrade overwrites that folder. It does not run the previous uninstaller, and it does not wait on a permission dialog.
- Setup closes the running app and waits until that process is gone before it opens the new one. The new copy then stays open.
- The first launch of 0.1.14 removes a leftover Prompt Picker install in another folder and points the Desktop shortcut at the program that is running.
- A PC that was wiped clean just gets one install. Nothing has to be deleted by hand.

## Uninstall

- One window. A second launch, including the installer's own relaunch, exits instead of opening another page.
- Prompt Picker is closed before the page appears. Uninstall does not start the app.

## Still in this version

- A picked prompt whose label matches New has a remove button on that result chip. Removing it can be undone and redone.
- Settings > Others includes Contact: Discord (fastest reply), Patreon, X, and Telegram (https://t.me/linekoaiart).
