# Prompt Picker 0.1.11

**18+.** Prompt Picker is for adults. The first launch asks "Are you 18 or older?" Yes is remembered on this PC. No closes the app.

## Update

- If update fails on 0.1.6/0.1.7, download and install this version manually once. After that, auto-update can install later versions. Copies already on 0.1.6 or 0.1.7 keep the old publisher check inside their own install, so they cannot be fixed by an automatic update.
- This build does not write `publisherName` into `app-update.yml`, and it does not require a signature check for later updates. The author and copyright stay in the app metadata.
- 0.1.9 and 0.1.10 could close as soon as the download finished without installing the new version, because the silent installer was pointed at the wrong folder. If you are still on 0.1.9 or 0.1.10, download and install 0.1.11 manually once. The app is unsigned: if Windows SmartScreen appears, choose More info, then Run anyway.
- The update dialog asks once for each version. A progress bar shows the download percent. Restart stays off until the download has finished, then installs into the current folder and opens the app again. Later remembers that version on this PC. If the update fails, the dialog shows a manual download link. Prompts are not deleted.

## Prompt Pick

- Pick existing uses two boxes side by side. The left box filters by name or source. The right box filters by a finished row, or a range such as 63-64. Both filters apply together. An empty box shows everything.

## Prompt Log

- Each character's finished rows stay in the order they were logged or imported. Copy and export use that logged order.
- The selected character's row list has its own sort: Row ascending, Row descending, Pick order oldest to newest, or Pick order newest to oldest. Pick order oldest to newest is the default. The choice is remembered on this PC and changes only what you see.
- The Prompt Log title, tool buttons, and search boxes stay fully visible. Only the character list and that character's row list scroll.
