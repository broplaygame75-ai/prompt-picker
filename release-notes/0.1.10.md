# Prompt Picker 0.1.10

**18+.** Prompt Picker is for adults. The first launch asks "Are you 18 or older?" Yes is remembered on this PC. No closes the app.

## Update

- If update fails on 0.1.6/0.1.7, download and install this version manually once. After that, auto-update can install later versions. Copies already on 0.1.6 or 0.1.7 keep the old publisher check inside their own install, so they cannot be fixed by an automatic update.
- This build does not write `publisherName` into `app-update.yml`, and it does not require a signature check for later updates. The author and copyright stay in the app metadata.

## Prompt Log

- The character list and that character's logged prompts each scroll inside the window. A long log no longer paints past the bottom of the panel.
- Sort the character list by name (A-Z or Z-A), date added, or date modified, newest or oldest. The choice is remembered on this PC. Each character stores when it was added and when its log last changed. Imported characters that have no dates use the import time.
- Two search boxes replace the single log search. The box above the character list matches the name or the source, either part of Name - Source. The box above the logged prompts matches that character's prompt name, label, a tag in the prompt text, or a row number. An empty box shows everything.
- Clear rows sits with the log tools. Target can be one character, several characters you check, or all characters. Leave Target empty and it stays on All characters. An optional label box accepts a label, or a pattern such as %new%. Leave it empty to clear every logged row for the target. %new% clears only rows whose prompt label contains new. A confirm dialog tells you how many rows across how many characters will be removed. Ctrl+Z undoes it and Ctrl+Y puts it back. Undo and Redo on the Prompt Pick tab are unchanged. Clearing rows updates the date modified for each character that lost a row.
