# Prompt Picker 0.1.3

**18+.** Prompt Picker is for adults.

This is the first published Windows installer.

- Pick a prompt at random and copy it.
- Keep a library of prompts with result images.
- Filter safe (SFW) and adult (NSFW) prompts. Current versions call these Mild and Explicit.
- Export a backup of prompts and images.
- The app checks for updates. Installing an update does not delete prompts.

Windows may say "Windows protected your PC" because the installer is not code-signed. Choose More info, then Run anyway. Do not turn off SmartScreen or Defender.
