# Prompt Picker 0.1.4

**18+.** Prompt Picker is for adults.

- The window is split into Prompt Pick, Prompts Data, and Prompt Log.
- Each prompt has a stable row number, shown as #12, and that number stays when other prompts are deleted.
- Prompt JSON can be exported and imported. Matching row numbers update, new rows are added, and the app asks before overwriting.
- English and Vietnamese can be switched.
- Copying a prompt logs it for a Name - Source character instead of only counting uses.
- Prompt Pick uses one slot.
- The update dialog no longer opens empty.

Windows may say "Windows protected your PC" because the installer is not code-signed. Choose More info, then Run anyway. Do not turn off SmartScreen or Defender.
