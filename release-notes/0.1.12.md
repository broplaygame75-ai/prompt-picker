# Prompt Picker 0.1.12

**18+.** Prompt Picker is for adults. The first launch asks "Are you 18 or older?" Yes is remembered on this PC. No closes the app.

## Update

- If update fails on 0.1.6/0.1.7, download and install this version manually once. After that, auto-update can install later versions. Copies already on 0.1.6 or 0.1.7 keep the old publisher check inside their own install, so they cannot be fixed by an automatic update.
- This build does not write `publisherName` into `app-update.yml`, and it does not require a signature check for later updates. The author and copyright stay in the app metadata.
- 0.1.9 and 0.1.10 could close as soon as the download finished without installing the new version. 0.1.11 could leave the Start Menu shortcut pointing at a folder that had been deleted, so Windows reported "Unspecified error" and the app did not stay open. If you are still on 0.1.9, 0.1.10, or 0.1.11, download and install 0.1.12 manually once. The app is unsigned: if Windows SmartScreen appears, choose More info, then Run anyway.
- The update dialog asks once for each version. A progress bar shows the download percent. Restart stays off until the download has finished, then installs into the current folder and opens the app again. Later remembers that version on this PC. If the update fails, the dialog shows a manual download link. Prompts are not deleted.

## Shortcuts and startup

- Every launch checks the Start Menu and Desktop shortcuts. If one is missing, or it points at an old program file, Prompt Picker rewrites it to the program that is running. You do not look up the program path.
- The installer does the same after it copies the files. A saved install folder that no longer exists is ignored, and the shortcuts are created for the program that was just installed. Uninstall removes those shortcuts.
- If Prompt Picker hits a startup error, a dialog explains it and offers Repair. Repair downloads the latest installer and opens it. A crash log is saved in the app data folder.

## Prompt Log

- With no characters yet, the two list panes keep a usable height and fill the space under the Sort and Rows choices. The empty sentence is fully visible. The title, tool buttons, and search boxes stay natural-height rows.
