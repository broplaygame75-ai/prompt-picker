# Prompt Picker 0.1.7

**18+.** Prompt Picker is for adults. The first launch asks "Are you 18 or older?" Yes is remembered on this PC. No closes the app.

## Help

- The shortcut line is gone from the header and from the Prompt Pick panel.
- Pick and Copy keys work only on the Prompt Pick tab, and not while you are typing. Defaults are R to pick and Q to copy.
- Settings has a Shortcuts tab. Click a field, then press a key or combination for Pick, Copy, and the text-size keys. A warning appears if that key is already used. Reset to default restores R, Q, Ctrl+=, Ctrl+-, and Ctrl+0. The choice is saved on this PC. The tour and the help text use the current keys.
- Long helper paragraphs are replaced by a small … button beside each feature. The first click shows a short tip, the second shows the full note, and the third collapses it back to ….
- A ! button next to the gear opens a step-by-step tour (spotlight, Next, Back, page dots, and Skip) or a written guide for Prompt Pick, Prompts Data, Prompt Log, and Settings. The tour starts once, after the age question, the first time the app is opened. Skip or finish remembers that choice.
- Settings, on the Language tab, has Hide all hints. That hides the … buttons too.

## Prompts, paste, and the log

- The add and edit form no longer has a separate Notes chip field. Keep the usage note, and put a short note in the name with quotes, such as Boothill "rain". Notes that were not part of the name are appended to the usage note.
- New prompts have a Create prompt button. Enter saves a one-line field. Ctrl+Enter saves while the cursor is in the prompt text.
- Paste prompts moved out of Settings. The button is next to Add prompt on the Prompts Data tab.
- A full backup includes prompts, the prompt log, and images. Prompts-only JSON also includes characters and finished rows. Import restores both.
- Prompt Log accepts lines in the form [Name][Source][12, 45, 171], for example [Boothill][HSR][12, 45, 171]. Copy as text uses the same form.

## Settings and type

- Version and Check for updates are on the Updates tab. The Data tab keeps the data folder and Reset.
- English and Vietnamese use Lexend at regular weight 400, with a slightly larger base size and line height 1.5. Atkinson Hyperlegible Next does not cover Vietnamese letters such as ơ and ư, so Lexend is used instead. Chinese stays on Noto Sans SC and Korean stays on Noto Sans KR. Thin weights are not used.
- Text wraps inside the window at narrow widths and at larger font sizes, including the Go to prompt row.
