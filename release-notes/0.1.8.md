# Prompt Picker 0.1.8

**18+.** Prompt Picker is for adults. The first launch asks "Are you 18 or older?" Yes is remembered on this PC. No closes the app.

## Update

- Auto-update from 0.1.6 to 0.1.7 failed with "New version 0.1.7 is not signed by the application owner: publisherNames: Lineko". The app is not code-signed, and the Windows build was still naming Lineko as the signature publisher, so the updater rejected the installer.
- This build does not write `publisherName` into `app-update.yml`, and it does not require a signature check for later updates. The author and copyright stay Lineko.
- If update fails on 0.1.6/0.1.7, download and install this version manually once. After that, auto-update can install later versions. Copies already on 0.1.6 or 0.1.7 keep the old publisher check inside their own install, so they cannot be fixed by an automatic update.

## Update now

- Update now closes the Settings window and asks in the main window: "Install update 0.x.x now? The app will restart." Yes starts the download and shows progress. Later leaves the app as it is. When the download finishes, Prompt Picker quits, installs silently, and opens again. Prompts are not deleted.

## Uninstall

- The uninstaller warns: "If you still have prompt data, open Prompt Picker and export a JSON backup (Settings > Backup & Import) before uninstalling." Vietnamese, Chinese, and Korean use the language chosen when Prompt Picker was installed.
- Uninstall removes the program from the folder saved in the registry, including a folder on a drive other than C:. It deletes the app exe, uninstaller, runtime libraries, paks, locales, and resources, then removes that folder only when it is empty. Files you added in that folder stay.
- Prompt data stays unless you check "Delete the prompt data folders listed below". The box starts unchecked. The page lists the folders it found: `%APPDATA%\Prompt Picker\data`, `PromptPickerData` inside the install folder, and a custom data folder the app recorded.
- Shortcuts, the installer's registry keys, and the `%LOCALAPPDATA%\prompt-picker-updater` cache are removed. Updating the app does not delete prompt data.

## Settings

- The Settings window no longer has a Close button next to the title. Use the window's own close button. The guide, the update prompt, and the tour still have their own dismiss actions, because those are panels inside the app and not separate windows.
