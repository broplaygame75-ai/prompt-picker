# Prompt Picker 0.1.15

**18+.** Prompt Picker is for adults. The first launch asks "Are you 18 or older?" Yes is remembered on this PC. No closes the app.

## Installer

- Setup stays on the file you opened. It does not start that exe again, and it does not delete or move it.
- A running Prompt Picker is closed only when its full path is the folder being installed. The setup process and its parent are left alone.
- The install log is `%TEMP%\PromptPicker-Setup.log`.

## Still in this version

- An update from 0.1.12 installs into the existing folder, including `%LOCALAPPDATA%\Programs\Prompt Picker`.
- The first launch removes a leftover copy in another folder and points the Desktop shortcut at the running program.
- Uninstall shows one window, closes the app first, and does not start the app.
- A picked prompt whose label matches New has a remove button on that result chip.
- Settings > Others includes Contact: Discord (fastest reply), Patreon, X, and Telegram (https://t.me/linekoaiart).
