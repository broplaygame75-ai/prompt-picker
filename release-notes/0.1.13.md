# Prompt Picker 0.1.13

**18+.** Prompt Picker is for adults. The first launch asks "Are you 18 or older?" Yes is remembered on this PC. No closes the app.

## Update

- If update fails on 0.1.6 or 0.1.7, download and install this version manually once. After that, auto-update can install later versions. Copies already on 0.1.6 or 0.1.7 keep the old publisher check inside their own install, so they cannot be fixed by an automatic update.
- This build does not write `publisherName` into `app-update.yml`. The author and copyright stay in the app metadata.
- The app is unsigned. If Windows SmartScreen appears, choose More info, then Run anyway.

## Install folder

- The installer asks for a folder. The suggested folder is `C:\Prompt Picker` when that location can be created. If it cannot, the suggestion is a `Prompt Picker` folder in your user profile. Administrator permission is requested only when the folder you chose cannot be written.
- The program files are placed in the folder you choose. An update installs into that same folder.
- Prompts stay in `%APPDATA%\Prompt Picker\data`.

## Shortcuts

- Only a Desktop shortcut is created. It points straight at the program file and does not carry an AppUserModelID.
- A Start Menu shortcut is not created. An existing Start Menu shortcut named Prompt Picker is removed during install and again each time the app opens. That old shortcut is what Windows reported as "Unspecified error": it stored AppUserModelID `com.lineko.promptpicker`, and the Start Menu cannot activate that id for this app. 0.1.12 wrote the same id back onto the shortcut every time the app opened.
- Each launch writes `%APPDATA%\Prompt Picker\startup.log`. The log records whether the program file exists, whether a shortcut still has an AppUserModelID, whether the shortcut target is missing, the Mark of the Web on the program file, and whether Windows Defender reported this app.
