# Contributing

This repository publishes Windows installers and documentation only. It does not contain the Prompt Picker source, and pull requests that add application source will not be merged.

Useful contributions are:

- Bug reports, with the app version, the Windows version, the steps, and `%APPDATA%\Prompt Picker\startup.log` or `crash.log` when you have them.
- Feature requests that describe the behavior you want.
- Corrections to the public install guide, README, or other documentation in this repository. Open a pull request only for those public-doc corrections.

Discord is the fastest place to talk: https://discord.gg/yH5AAdj5qY

Please keep reports safe for work. Do not paste prompt text that you would not want public.
