# Install Prompt Picker {{version}}

**18+.** This app is for adults. The pictures below are illustrations.

Windows may say "Windows protected your PC" because the app is not code-signed. Click More info, then Run anyway. Do not turn off SmartScreen or Defender.

Auto-update keeps using `PromptPicker-Setup-{{version}}.exe` and `latest.yml`. This zip adds the guide and the pictures beside that exe.

An update installs into the folder you already chose. It does not delete prompts or settings.

Uninstall has two choices, in the app and in Windows Settings > Apps. **Uninstall, keep data** keeps prompts, settings (language, theme, sorts, hints, and every other preference), and install choices. The next install prefills that folder and those options, then restores the settings. **Uninstall and wipe everything** removes those too.
