JSON prompt

File JSON dễ đọc và sửa: số hàng, rating (SFW/NSFW), tên, theme và nội dung prompt. Có thể kèm nhân vật và hàng đã xong. Nhập sẽ cập nhật prompt theo số hàng, thêm hàng mới, và hỏi trước khi ghi đè.
