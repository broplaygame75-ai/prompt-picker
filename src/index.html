Paste prompts

Paste one or more prompts like [SFW][Name &New&&Halloween& "note"][prompt…], [NSFW][Name][prompt]. In the name, &label& is a label and quotes are a note. Tags are the comma-separated parts of the prompt text. () [] {} in the prompt are kept as written. [SFW] is Mild, [NSFW] is Explicit, and [ALL] is All levels.

Preview reads the paste box. Add all saves those rows and skips duplicates.

Label manager

Every label found on a prompt is listed here. Allow filtering puts it in the filter dropdown, Exclude by label, and Priority. New, Nope, and holiday labels start on. Other labels are descriptive: they stay on the card as a muted chip and are not filterable.

Theme colors

Primary and Secondary color the gradient on buttons, the logo, and active tabs. App background and Panel background color the page and the cards, and text contrast adjusts so it stays readable. OK saves on this PC.
