Paste prompts

Paste one or more prompts like [SFW][Name &New&&Halloween& "note"][prompt…], [NSFW][Name][prompt]. In the name, &label& is a label and quotes are a note. Tags are the comma-separated parts of the prompt text. () [] {} in the prompt are kept as written. [SFW] is Mild, [NSFW] is Explicit, and [ALL] is All levels.

Preview reads the paste box. Add all saves those rows and skips duplicates.

Each Name - Source character has the prompt rows copied for them. Delete a row to remove it from that log when the prompt has been updated. A row is flagged if the prompt changed after it was logged.

Settings

Language

Choose the language for every label, the help under each control, and the update dialog. The choice is remembered on this PC.

Font size

Scales every label in the main window and this window. The size is saved on this PC.

Default 100%

Defaults: Ctrl+= larger, Ctrl+- smaller, Ctrl+0 default. Change them on the Shortcuts tab.

Shortcuts

Click a key, then press the new key or combination. Pick, Copy, Undo, and Redo work only on the Prompt Pick tab, and not while you are typing. Reset to default restores R, Q, Ctrl+Z, Ctrl+Y, and the zoom keys.

Label manager

Every label found on a prompt is listed here. Allow filtering puts it in the filter dropdown, Exclude by label, and Priority. New, Nope, and holiday labels start on. Other labels are descriptive: they stay on the card as a muted chip and are not filterable.

Theme colors

Primary and Secondary color the gradient on buttons, the logo, and active tabs. App background and Panel background color the page and the cards, and text contrast adjusts so it stays readable. OK saves on this PC.

Backup & Import

Full backup includes prompts, the prompt log, and images. Prompts only is readable JSON of every prompt plus characters and finished rows. Import restores both.

Import detects a full backup, prompt JSON, or paste text. A full backup and prompt JSON both restore prompts and the prompt log. Prompt JSON updates by row, adds rows, and asks before overwriting.

Updates

Prompt Picker checks for a new version when it opens and about every 30 minutes. Update now closes Settings and asks in the main window before it downloads. The app then restarts. Prompts are not deleted.
